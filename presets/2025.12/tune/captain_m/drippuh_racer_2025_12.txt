# --- SWITCHABLE QUADS ---
# Select which quad this is. Each quad listens on its own AUX8 band, so a single
# radio model can be pointed at any one of them by changing the AUX8 value.
#
# Each option sets the craft name and puts the quad into FAILSAFE (mode 27)
# whenever AUX8 is NOT in this quad's band, so pointing the radio at a different
# quad keeps this one on the ground. Failsafe cuts the motors.
#
# Mode 27 is the FAILSAFE *permanent ID* used by the CLI, which is a different
# numbering from the internal boxId enum. The aux channel argument is
# AUX-relative, so 7 = AUX8.
#$ OPTION_GROUP BEGIN: Switchable Quads
    #$ OPTION BEGIN (UNCHECKED): Drone #1
        set craft_name = Drippuh #1

        # AUX8 is 988 for this quad -> valid band 900-1100
        # FAILSAFE (mode 27) whenever AUX8 falls outside that band
        aux 2 27 7 1100 2100 0 0
    #$ OPTION END

    #$ OPTION BEGIN (UNCHECKED): Drone #2
